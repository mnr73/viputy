# Introduction

viputy is a set of Vue 3 inputs for Persian forms: full RTL, Jalali calendar, plain CSS variables (no Tailwind, no runtime dependencies) and SSR-safe.

1.0 is a ground-up rewrite. The previous line lives on the `legacy/0.x` branch.

Go to [Install & use](/en/guide/install).

Coming from the previous version? See the [migration guide](/en/guide/migration). For AI agents: the [skill](/en/guide/ai-skill).
