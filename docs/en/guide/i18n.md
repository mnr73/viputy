# Locale & RTL

```ts
app.use(viputy, { locale: "fa" });             // Persian messages, RTL
app.use(viputy, { locale: "en", dir: "rtl" }); // force direction
app.use(viputy, {
  locale: "fa",
  messages: { fa: { clear: "Remove all" } }    // override texts
});
```

`locale` may be a ref or getter; everything updates when it changes. Built in: `fa`, `en`. Unknown locales fall back to English.

Text helpers:

```ts
import { toLatinDigits, toPersianDigits, normalizeText } from "@mnr73/viputy";

toLatinDigits("۱۴۰۵");       // "1405"    (before sending to a server)
toPersianDigits(2450000);    // "۲۴۵۰۰۰۰"  (display only)
normalizeText("عليكم");       // "علیکم"   (for searching)
```
