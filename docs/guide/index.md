# معرفی

viputy مجموعه‌ای از اینپوت‌های Vue 3 است برای فرم‌های فارسی: RTL کامل، تقویم جلالی، CSS ساده با متغیر (بدون Tailwind و بدون وابستگی runtime) و سازگار با SSR.

نسخه ۱.۰ بازنویسی کامل است. نسخه‌ی قبلی روی شاخه‌ی `legacy/0.x` مانده.

برو به [نصب و استفاده](/guide/install).

مهاجرت از نسخه‌ی قبل: [راهنمای مهاجرت](/guide/migration). برای ایجنت‌های هوش مصنوعی: [اسکیل](/guide/ai-skill).
