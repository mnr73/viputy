# زبان و RTL

```ts
app.use(viputy, { locale: "fa" });             // پیام‌ها فارسی، جهت RTL
app.use(viputy, { locale: "en", dir: "rtl" }); // جهت را دستی عوض کن
app.use(viputy, {
  locale: "fa",
  messages: { fa: { clear: "حذف همه" } }       // override متن‌ها
});
```

`locale` می‌تواند ref یا getter باشد و با تغییرش همه‌چیز آپدیت می‌شود. زبان‌های داخلی: `fa` و `en`. زبان ناشناخته به انگلیسی برمی‌گردد.

ابزارهای متن:

```ts
import { toLatinDigits, toPersianDigits, normalizeText } from "@mnr73/viputy";

toLatinDigits("۱۴۰۵");       // "1405"    (قبل از ارسال به سرور)
toPersianDigits(2450000);    // "۲۴۵۰۰۰۰"  (فقط نمایش)
normalizeText("عليكم");       // "علیکم"   (برای جستجو)
```
